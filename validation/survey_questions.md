## Google Forms Setup Instructions

1. Go to [forms.google.com](https://forms.google.com)
2. Click "+ Blank" to create new form
3. Title: "LinkedIn Content & Job Search Survey"
4. Add description from Survey Header above
5. For each question:
   - Click "+" to add question
   - Set question type (Multiple choice, Checkboxes, Grid, etc.)
   - Copy question text
   - Add all options
   - Click "Required" toggle (except email and additional thoughts)
6. Settings (gear icon):
   - ✅ Limit to 1 response (prevents spam)
   - ✅ Shuffle question order (for ranking questions only)
   - ✅ Show progress bar
7. Presentation (palette icon):
   - Add progress bar
   - Customize thank you message
8. Click "Send" → Get shareable link

**Test it yourself before launching!**

## Tips for Better Responses

### Question Order Matters
- Start with easy qualifying questions
- Put effort questions (ranking) in middle
- End with commitment (email, beta signup)
- This improves completion rate

### Answer Options Best Practices
- Always include "Other" option where relevant
- Use specific ranges ($40-59) not vague (moderate)
- Keep option text short (10 words max)
- Make options mutually exclusive

### Common Mistakes to Avoid
- ❌ Too many required questions (causes dropoff)
- ❌ Vague options ("somewhat expensive")
- ❌ Double-barreled questions (asking 2 things at once)
- ❌ Leading questions ("Don't you think...")
- ❌ Jargon or complex language

### Quality Checks
Before launching, test:
- [ ] Takes <3 minutes to complete
- [ ] All questions make sense on mobile
- [ ] Thank you page displays correctly
- [ ] Email validation works
- [ ] Shareable link works in incognito window
